# Tamagochi Game

🎮 Тамагочи‑кликер на Python. Учебный проект с чистой архитектурой и проверкой стиля кода.

Проект демонстрирует:
- работу с абстрактными классами (`abc.ABC`);
- обработку исключений для валидных игровых ситуаций;
- соблюдение стандартов стиля кода (проверка через `ruff`);
- модульную структуру (разделение логики игры и модели питомца).
